# Сервис управления посылками (ParcelStore)

## БД на основе SQLite

## Основные функции:
- **Регистрация новой посылки** 
- **Просмотр информации о посылке** 
- **Получение списка посылок клиента** 
- **Обновление статуса посылки** 
- **Изменение адреса посылки** 
- **Удаление посылки** 

### В проекте настроены workflow для автоматического тестирования и публикации приложения в DockerHub. Имеется два jobs:
- **Проверяет код на наличие ошибок и запускает тесты**
- **При добавлении тегов автоматически публикует приложение в DockerHub**
